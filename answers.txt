# Файл автоответов бота
# Формат строки:
#   [каналы]"триггер1","триггер2",...="ответ бота"
#
# [каналы] — список номеров каналов через запятую. Бот анализирует сообщения
#            только из указанных каналов. Используйте * для всех каналов.
# триггеры — текст (в кавычках), который ищется в сообщении (без учёта регистра,
#            в любой части сообщения). Несколько триггеров через запятую — любой из них.
# ответ    — текст ответа бота (в кавычках).
#
# Строки начинающиеся с # — комментарии, игнорируются.
# Пустые строки игнорируются.
#
# Примеры:

[0]"Привет","Прив","👋"="Всем привет!"
[0,1,2,3]"погода","weather"="Используй команду /weather для погоды"
[*]"спасибо","thanks","👍"="Пожалуйста!"
